# Preface

Although JavaScript in Mindustry is quite controversial, and mainstream mods are rarely written in JS — for developers without a PC or those who only want to make small extensions on top of JSON, JS can be a solid choice.

This tutorial aims to provide basic development思路 for JS mod beginners, offer some templates to help with mod development, and most importantly, teach you how to read Java source code so you can achieve the effects you want by consulting the source directly.

Before reading this tutorial, you should at least have the following knowledge and skills:

- Basic arithmetic;
- Basic programming knowledge — at minimum, know what variables, functions, objects, etc. are;
- The ability to read articles word by word and absorb the content;
- **A heart that is always learning**
